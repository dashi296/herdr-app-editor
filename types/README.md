# Host type declarations

Herdr writes these files into the app home on every start. They are copied here so `src/adapters`, `src/ui` and `src/entries` can be typechecked (`tsconfig.host.json`).

| File | Source |
|---|---|
| `herdr.d.ts` | Generated by Herdr Desktop 0.1.16 (`~/.config/herdr-app/herdr.d.ts`) |
| `gpui-kit.d.ts` | Generated by Herdr Desktop 0.1.16 (`~/.config/herdr-app/gpui-kit.d.ts`) |
