# Host type declarations

Herdr writes these files into the app home on every start. They are copied here so `src/adapters`, `src/ui` and `src/entries` can be typechecked (`tsconfig.host.json`).

| File | Source | Note |
|---|---|---|
| `herdr.d.ts` | herdrdev/herdr-app `5216e6f` (master, 2026-11-14) `defaults/herdr.d.ts` | The plan targets the next release (0.1.16 or later), which includes these APIs |
| `gpui-kit.d.ts` | Generated by Herdr Desktop 0.1.15 (`~/.config/herdr-app/gpui-kit.d.ts`) | master generates it from Rust, so no file exists for master. APIs added in master are declared in `gpui-next.d.ts` |
| `gpui-next.d.ts` | Written by this repository | Additions in master `vendor/gpui-kit/crates/shell/src/typings.rs` that 0.1.15 lacks (`EditorState.focus` and others) |
