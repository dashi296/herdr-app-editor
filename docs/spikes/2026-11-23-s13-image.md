# S13: `image()` でアプリホームの外にある画像を表示できるか

実施日: 2026-11-23 / 環境: macOS、Herdr Desktop 0.1.16 / 目的: エディタペインで画像ファイルを表示できるかを決める（#42）

## 型定義から分かること

- `gpui-kit` の `image(path)` は「アプリケーション自身のディレクトリからのフルカラー画像」。パスはアプリホーム（`~/.config/herdr-app`）を基準に解決される。
- 縦横比を保って収める指定（object-fit に当たるもの）はない。
- web view と PDF の要素はない（AGENTS.md: "You can't: use HTML, CSS, a web view"）。
- バイナリを読む API は `fs/promises` の `readFile`（ホーム配下のみ読める）だけ。`readTextFile` は UTF-8 のテキスト専用。

## 手順

使い捨ての mod（`spikes/s13-image/`、オーバーレイ）を `~/.config/herdr-app/mods/` に置き、`herdr-app shot` で撮った。1秒ごとに `cx.notify()` する数字を表示し、view が作り直されないことも見た。

## 結果

### 読めるパス

| 渡したパス | 表示 |
|---|---|
| アプリホームからの相対パス（`mods/<mod>/cache/x.png`、`data/<mod>/x.png`） | される |
| 絶対パス | されない（34秒待っても空） |
| `../../projects/…` | されない（同上） |
| `~/…` | されない（同上） |
| `file://…` | されない |
| アプリホーム配下に置いた、外のファイルへの symlink | される |
| 存在しないパス | 空。`herdr-app status` の `errors` にも何も出ない |

### 形式

png、jpg、webp、gif、bmp、tiff、svg、拡張子のない jpg、8000×6000 の png は表示された。avif と heic は空のままだった。

### 表示までの時間

- view が毎秒描き直されている状態で、リンクを作って `image()` に渡してから 0.1〜0.9 秒で表示された（3回）。
- 描き直しのない view では、読み込みが終わっても描き直されない。実際のエディタペインでは開いて3秒後もまだ空で、その後の撮影では表示されていた。開いた直後は `cx.notify()` を繰り返す必要がある。

### 同じパスの差し替え

表示済みの `data/<mod>/x.png` について、symlink の向き先を変えても、通常ファイルを上書きしても、16秒後も元の絵のままだった。ホストはパスごとに読んだ結果を覚えている。開くたびに新しい名前を使う必要がある。

### 動作中の mod への影響

`data/<mod>/` にファイルを足しても、view は作り直されなかった（数字が続きから増えた）。

### ボックスに収める指定

| 指定 | 結果 |
|---|---|
| `w(a).h(b)` | 幅 a、高さは縦横比から決まり、b を超えるとはみ出す |
| `w(a)` だけ / `h(b)` だけ / `max_w(a)` だけ | 縦横比を保つ |
| `size_full()`、`h_full()`、`w_full()` | 向きによってはみ出すか、表示されない |
| 親を `flex().items_center().justify_center()` にして `max_w_full().max_h_full()` | 横長・縦長の画像と横長・縦長のボックスの組み合わせで、収まって中央に出た。24×24 の画像は拡大されなかった |

はみ出した部分は隣の要素の上に描かれる。`overflow_hidden()` で包む必要がある。

## 結論

- 画像は表示できる。アプリホーム配下（`data/herdr-app-editor/images/<pane key>/`）に symlink を作り、その相対パスを `image()` に渡す。コピーは要らない。
- リンクの名前は開くたびに変える。
- 収め方は、中央寄せの flex の親と `max_w_full().max_h_full()`、外側に `overflow_hidden()`。
- avif と heic は表示できない。
- 他のマシン上の画像は、この方法では表示できない（リンクはこのコンピューターで作る）。
- PDF は `image()` に渡せる形式ではない。ページを画像に変換する別の手段が要る（#43）。

## 片付け

オーバーレイを `mod.open` で閉じてから、`mods/zz-image-spike/` と `data/zz-image-spike/` を消した。`status` の `overlays` と `errors` は空。
